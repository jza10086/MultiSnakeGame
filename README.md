# 蛇蛇大作战 · MultiSnakeGame

GodotParty API 4 / manifest 2 小游戏，适配 GodotPartyDefaultProtocol 1.0 普通排名局。安装在 `games/minigame/godot_party_default_multi_snake_game/`，从正式大厅的小游戏轮换中选择；本仓库是内容包，依赖宿主工程及协议，不是独立 Godot 工程。

- 支持 1–8 人在线同场；单人可练习，无 AI、无同屏本地多人。
- 鼠标指向转向，或按住 WASD / 方向键。鼠标左键 / 空格加速，Tab 按住展开排名，Esc 打开框架菜单。动作可在本机设置中重绑。
- 吞食光点增长，蛇头撞到其他蛇（含蛇头）或圆形边界即死亡；自己的身体可穿过，同时对撞双方死亡。
- 3 秒自动复活，复活后重置当前长度，最高长度与击败数保留。出生 2 秒内与其他蛇互相无碰撞，但仍不能越过边界。
- 初始长度 22，上限 220；加速每秒消耗 3 长度，低于 23 时停止加速。死亡掉落额外成长部分的 70%，初始长度不掉落。
- 默认 180 秒，房主可配置 30–600 秒。按本轮最高长度排名，相同长度并列；离线玩家退出本轮且不再复活。

房主固定 60 Hz 模拟，客户端 20 Hz 发送逻辑转向与加速，约 12.5 Hz 接收有序快照并插值显示；姓名与颜色取房间资料。`snake_world.gd` 管规则，`arena_view.gd` 管绘制，`game.gd` 管生命周期与网络。

美术为程序绘制，没有外部下载资产。不使用或包含 Slither.io 的品牌和素材。
