# 蛇蛇大作战 · MultiSnakeGame

GodotParty API 4 / manifest 2 小游戏，适配 GodotPartyDefaultProtocol 1.0 普通排名局。安装在 `games/minigame/gp_snake_battle/`，从正式大厅的小游戏轮换中选择；本仓库是内容包，依赖宿主工程及协议，不是独立 Godot 工程。

- 支持 1–8 人在线同场；单人可练习，无 AI、无同屏本地多人。
- 鼠标指向转向，或按住 WASD / 方向键。鼠标左键 / 空格加速，R 按住展开本局排名，Tab 按住查看框架延迟面板，Esc 打开框架菜单。动作可在本机设置中重绑。
- 吞食光点增长，蛇头撞到其他蛇（含蛇头）或圆形边界即死亡；自己的身体可穿过，同时对撞双方死亡。
- 3 秒自动复活，复活后重置当前长度，最高长度与击败数保留。出生 2 秒内与其他蛇互相无碰撞，但仍不能越过边界。
- 初始长度 22，上限 220；加速每秒消耗 3 长度，低于 23 时停止加速。死亡掉落额外成长部分的 70%，初始长度不掉落。
- 默认 180 秒，房主可配置 30–600 秒。按本轮最高长度排名，相同长度并列；离线玩家退出本轮且不再复活。

房主固定 60 Hz 模拟，客户端 20 Hz 发送不可靠有序的逻辑转向与加速；蛇出生/重生、长度与食物增删可靠通知，20 Hz 短蛇头轨迹在本地重建蛇身并插值显示，不重复发送完整蛇身和食物表；姓名与颜色取房间资料。`snake_world.gd` 管规则，`arena_view.gd` 管绘制，`game.gd` 管生命周期与网络。

HUD 的布局、示例文字和字体 Theme 保存在 `game.tscn`，启动不覆盖场景 Theme；示例不进入对局数据。排行榜复用同一 Label，显示内容由 `i18n/zh_Hans.po` 的命名参数模板生成；动态蛇身、光点和小地图继续由视图绘制。全榜动作在游戏输入可用时消费对应按键，避免同时打开框架排名弹窗。准备/结算仍使用协议现有 round_pages，共享生命周期迁移由协议统一处理。

美术为程序绘制，没有外部下载资产。不使用或包含 Slither.io 的品牌和素材。

1–8 人同场蛇蛇竞技：鼠标或方向键转向，吞食光点成长，加速消耗长度。撞墙或撞到别人的蛇身会死亡，3 秒后自动复活，出生保护 2 秒。可以穿过自己。默认 3 分钟，按本轮最高长度排名。
